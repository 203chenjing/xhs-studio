# 校招投递助手 · 浏览器插件

**一句话：** 正常投递自动记台账（默认），填表是辅助，补充只在识别不准时用。

当前版本：**1.8.0**（UX 重建：三 Tab 主流程、简历 AI 解析预览、Shadow DOM 填表助手）

## 端到端使用流程

```
首次安装 → 设置 API Key → 编辑简历（AI 解析）→ 保存版本
    → 打开网申页 → Popup「填表」引导 → 侧边栏填表 → 自动记录投递
```

| 步骤 | 做什么 | 在哪 |
|------|--------|------|
| **① 设置** | 配置 API Key（可选，AI 解析/开放题需要） | 扩展 Popup → 设置 |
| **② 简历** | 粘贴文本 → AI 解析 → 预览确认 → 保存版本 | Popup → 编辑简历 |
| **③ 记录** | 看投了哪些、待确认条数（默认 Tab） | Popup「记录」— 多数时候不用操作 |
| **④ 填表** | 选版本 → 开助手/一键填充 → 标记已填表 | Popup「填表」 |
| **⑤ 补充** | 识别错了才手动改、导入导出 | Popup「补充」 |

**正常投递即可，无需操作。** 成功页、测评页、提交后会自动写入台账；扩展图标 badge 橙色 = 有待确认、数字 = 已记录条数。

## 三 Tab 心智模型

| Tab | 用途 |
|-----|------|
| **记录** | 自动捕获状态、待确认、最近台账 |
| **填表** | 三步向导：选版本 → 开助手 → 标记 |
| **补充** | 手动补全、导入导出（折叠在底部） |

## AI Native 产品闭环

```
选简历版本 → 网申填表(算法) → 标记/自动记录「用哪版简历填了哪家」→ 台账可查
```

| 环节 | 能力 | AI？ |
|------|------|------|
| 选版本 | Popup「填表」切换简历版本；可选「AI 推荐版本」 | 仅点击时 |
| 填表 | 侧边栏点填 / 一键填充；会话追踪已填字段数 | 否 |
| 开放题 | 侧边栏「AI 写开放题」（需聚焦 textarea） | 仅点击时 |
| 记台账 | 「标记已填表」或成功页自动捕获，绑定 `resumeVersion` | 否 |
| 查记录 | 记录 Tab 按版本筛选 + 统计 | 否 |

典型消耗：规则填表 **0 token**；开放题/推荐版本约 200–400 token/次（你主动触发）。

## 功能

- **静默自动捕获**：仅在招聘/校招/测评页生效；**列表页浏览选岗时不记录**
- **触发条件**：
  - 页面出现「投递成功」「提交成功」等文案
  - 点击「投递 / 申请 / 提交」且后续页面确认成功
  - 进入北森 / 牛客 / ShowMeBug 等测评页
- **Popup 管理**：查看、搜索、编辑、删除、**读取当前页**（规则引擎，即时）、导出 TSV
- **AI 识别（可选、较慢）**：仅在设置中启用且手动点击「慢 · AI 识别」时调用；默认不走 AI
- **广泛站点覆盖**：80+ 规则，含 ATS 平台（Moka、北森、大易、Workday 等）及主流公司官网

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions/` 或 `edge://extensions/`
2. 开启 **开发者模式**
3. **加载已解压的扩展程序** → 选择 `job-tracker-extension`
4. 更新代码后点扩展卡片上的 **重新加载**

## 使用

1. **日常投递**：不用管插件，打开 Popup 默认在「记录」看台账即可
2. **网申填表**：Popup →「填表」→ 三步（选版本 → 助手/一键填充 → 标记已填表）
3. **识别不准**：待确认条在「记录」确认；要改字段去「补充」
4. **导出**：Popup「补充」底部 → 数据导入导出

## 填表助手（Shadow DOM）

参考 [jobfill](https://github.com/23aaaa/jobfill) 与 [CampusApply-Agent](https://github.com/hanjiayuan2025-coder/CampusApply-Agent) 集成：

| 功能 | 说明 |
|------|------|
| **侧边栏点填** | 招聘页右侧「填表助手」→ 先点网页输入框，再点字段按钮填入 |
| **下一个** | 按顺序跳转到下一个输入框 |
| **一键填充** | 按 ATS 规则 + 字段关键词自动匹配填充 |
| **编辑简历** | Popup →「编辑简历」填写姓名、多段教育/实习/项目 |

### 填表流程

1. Popup → **编辑简历** → 填写个人信息与多段经历 → 保存
2. Popup → **填表** → 选简历版本
3. 打开北森/Moka/企业网申页 → **填表助手** 或 Popup「打开填表助手」
4. **手动模式**：点输入框 → 点侧边栏「姓名」「手机号」等
5. **自动模式**：点 **一键填充**（规则匹配，不耗 AI token）
6. 填完后 Popup → **标记已填表**

### 简历粘贴解析

编辑简历页 → 左侧粘贴 → 右侧预览卡片 → 确认合并：

- **AI 解析并填入**（默认，需 API Key）
- **仅本地快速解析**（离线兜底）
- 合并前预览确认，默认仅补充空白字段

## 算法优先，AI 可选兜底

识别链路（由快到慢，**默认 0 次 AI**）：

1. **站点规则**（`extractors.js`，80+ 条）
2. **启发式**（`extract-heuristics.js`）
3. **多信号融合**（`fusion-scorer.js`）
4. **实体去重**（`entity-resolution.js`）
5. **置信度路由** — 高置信直接入库；低置信进「待确认」
6. **AI**（可选）— 仅手动触发或显式开启「自动后台补全」

### DeepSeek API Key 与连通性测试

1. 扩展 Popup → **设置**（或打开 `options/options.html`）
2. 勾选 **启用 AI 增强**
3. 在 API Key 输入框粘贴 Key（仅英文 `sk-` 开头）
4. 确认 Base URL 为 `https://api.deepseek.com/v1`，模型为 `deepseek-chat`
5. 点击 **保存设置**，再点 **测试 AI 连接**

本地开发可用脚本验证：

```bash
cd job-tracker-extension
node scripts/test-api.mjs
```

可将 Key 放在已 gitignore 的 `.local-settings.json`。**切勿把真实 Key 提交到 git。**

## 文件结构

```
job-tracker-extension/
├── manifest.json
├── background.js
├── lib/           # 常量、存储、提取规则、ui-common.css
├── content/       # 静默捕获 + 填表助手（Shadow DOM）
├── popup/         # 扩展弹窗（记录 / 填表 / 补充）
├── resume/        # 简历编辑器
├── options/       # 设置页
└── icons/
```

数据保存在浏览器本地（`chrome.storage.local`），不上传服务器。
