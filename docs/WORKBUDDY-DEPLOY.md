## 2. 站点配置要求

1. **站点根目录 = `demo/`**，`index.html` 必须位于根路径。
2. 纯静态托管，**不需要 SPA rewrite / 路由**。
3. 开启 HTTPS。
4. MIME 类型（关键）：
   - `.woff2` → `font/woff2`
   - `.js` → `text/javascript`
   - `.css` → `text/css`
5. 如果只能挂在子路径（如 `/demo/`），确保以**带斜杠的目录**访问，并开启目录默认页。
6. 缓存：
   - 首次发布建议 HTML `no-cache` 或短缓存；
   - 资源文件名没有 hash，若托管有 CDN，发布后**清一次缓存**。
7. 不需要跨域、不需要服务端代理、不需要自定义 Header（除 MIME 外）。

## 6. 常见问题

**Q1：页面空白 / 资源 404**
站点根目录指错了。必须让 `index.html`、`assets/` 直接位于站点根，而不是仓库根或 zip 外层目录。

**Q2：字体没加载，标题变成系统字体**
托管未把 `.woff2` 识别为 `font/woff2`。在托管配置里补 MIME，或确认没有把字体目录排除。

**Q3：二维码扫出来是 localhost**
部署后打开 `/qr.html`，页面会自动用当前域名；如果你之前手动填过地址，点「恢复」即可。也可以直接在输入框粘贴正式地址。

**Q4：改了东西但线上还是旧版**
资源文件名没有 hash，需要清 CDN 缓存 + 强制刷新；发布时 HTML 建议 `no-cache`。

**Q5：挂在 `/demo`（无尾斜杠）打不开**
请配置 301 到 `/demo/`，或直接使用带斜杠的地址；相对路径依赖目录语义。

**Q6：导出很慢 / 手机上失败**
导出是浏览器内逐页渲染 2160×2880，7 页约 8MB，移动端需要几秒到十几秒；内存不足时会提示失败，可先用「复制」把文案带走。这不是托管问题。
